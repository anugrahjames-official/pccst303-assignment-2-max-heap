# PCCST303 Assignment 2

## Data Structures and Algorithms

### Topic

Max Heap vs Linear Search for finding the highest student score.

## Input

78, 92, 65, 88, 95, 72, 84, 90

## Objectives

- Implement a Max Heap in C
- Insert all student scores
- Record the heap after every insertion
- Find the maximum using Max Heap
- Find the maximum using Linear Search
- Compare the number of operations
- Analyse time and space complexity

## Result

Maximum score = 95
Max Heap maximum access = O(1)
Linear Search maximum = O(n)
Max Heap insertion = O(log n)

## Repository Structure

- `src/` - C source code
- `input/` - Input data
- `output/` - Program output
- `trace/` - Heap trace table
- `analysis/` - Complexity and comparison
