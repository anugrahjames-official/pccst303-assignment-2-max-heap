# Complexity Analysis

## Max Heap

| Operation | Complexity |
|---|---|
| Insert | O(log n) |
| Find Maximum | O(1) |
| Space | O(n) |

## Linear Search

| Operation | Complexity |
|---|---|
| Find Maximum | O(n) |
| Extra Space | O(1) |

## Conclusion
For continuously maintaining and frequently accessing the highest student score, a Max Heap provides O(1) maximum access while new scores can be inserted in O(log n).
